ThesisMatch

Die Plattform zur Vermittlung von Betreuung und Themen für Abschlussarbeiten am Institut für Informatik.

Was bietet diese Plattform?

  • Durchsuchen von Betreuerprofilen und Themenvorschlägen
  • Filtern nach Fachgebieten und Interessen
  • Matching basierend auf besuchten Veranstaltungen
  • Bereitstellung von Leitfäden und Dokumenten

Anmeldung

Die Anmeldung erfolgt über GitHub OAuth. Es werden keine Passwörter auf dieser Plattform gespeichert.

Hinweis: Studierende können Themen und Profile einsehen. Betreuende erhalten nach entsprechender Freischaltung zusätzliche Bearbeitungsrechte.
🐙 Mit GitHub anmelden

Nach erfolgreicher Authentifizierung werden Sie automatisch zur Plattform zurückgeleitet.
